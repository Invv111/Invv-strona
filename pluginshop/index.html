ShopPlugin

Classic Shop plugin for minecraft

Download 1.0-SNAPSHOT Open on Modrinth
1,464 downloads2 followersMinecraft 1.19 – 1.21.9Paper, SpigotUpdated 1 year ago

[⚠️]NOTE! If u have aby issue with the plugin please report to in our discord!

ShopPlugin lets players create chest-based shops with signs in Minecraft. Only the shop owner can edit the sign, open the chest, or destroy either, while others can buy items by right-clicking the sign. Supports Vault for economy or works without it. Supported Version: Minecraft 1.21.8 (Paper). Dependencies (economy version): Vault, economy plugin (e.g., EssentialsX). Usage:

Create a Shop:

  1. Place a chest with items (e.g., 5 diamonds). Add a sign nearby:

  2. With economy: [Shop], DIAMOND, 5, 100$ Without economy: [Shop], DIAMOND, 5

  3. The sign-placer becomes the owner.

  4. Buying: Non-owners right-click the sign to buy items (if funds/items available). Owner Privileges: Only the owner can edit the sign, open the chest, or destroy them. Installation: Place ShopPlugin-1.0-SNAPSHOT.jar in plugins, add Vault/EssentialsX (if using . economy), and restart.

🏠 SetHome

A lightweight plugin for multiple named homes. Players can set, list, teleport to, rename and delete their homes. Simple to use, fast, and safe for your data.

✅ Paper · Folia · Purpur · Spigot, from 1.21 to 26.3: one jar for all of them.

✨ Features

  • 📍 Multiple named homes, with the exact position and facing direction saved
  • ⚡ Async teleports on Paper/Folia: chunks load in the background, so there's no lag spike
  • 🌐 Full Folia support
  • 🔢 Per-rank home limits with permissions
  • ⏳ Optional teleport warmup (cancelled when you move) and cooldown
  • 🚫 Disabled worlds where homes can't be set
  • 💬 Every message configurable, with & colours and &#RRGGBB hex
  • ⌨️ Tab completion for home names
  • 💾 Homes are saved by UUID, so changing your nickname keeps your homes
  • 🛡️ Crash-safe background saving, and homes in unloaded worlds are never lost

🚀 Commands

Command Description Permission
/homes (/home) List your homes with coordinates homes.use
/homes <name> Teleport to a home homes.use
/sethome [name] Set a home (no name = home) homes.sethome
/delhome <name> Delete a home homes.delhome
/rehome <old> <new> Rename a home homes.rehome
/homes reload Reload config and homes (console too) homes.admin

🔑 Permissions

Permission Default Description
homes.use, homes.sethome, homes.delhome, homes.rehome everyone Basic commands
homes.limit.<n> – Home limit for a rank, e.g. homes.limit.10 (highest wins)
homes.unlimited – No home limit
homes.bypass.warmup op Instant teleport
homes.bypass.cooldown op Ignores the cooldown
homes.bypass.world op Can set homes in disabled worlds
homes.admin op Reload, plus all bypasses and unlimited homes

⚙️ Configuration

max-homes: 5                 # default limit (override with homes.limit.<n>)
default-home-name: home      # used by /sethome without a name
home-name-pattern: '^[a-zA-Z0-9_-]{1,16}$'

teleport:
  warmup: 0                  # seconds, 0 = instant
  cancel-on-move: true
  cooldown: 0                # seconds, 0 = off

disabled-worlds: []

messages:
  prefix: '&8[&aHomes&8] '
  # ...every message can be changed

Homes are stored in homes.yml. New config options are added automatically when you update.

📦 Requirements

  • Paper, Folia, Purpur or Spigot 1.21 – 26.3
  • Java 21+ (Java 25 on 26.x)

Updating from an older version? Just replace the jar. Your homes are migrated automatically. 🌍

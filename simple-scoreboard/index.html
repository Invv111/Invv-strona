📊 SimpleScoreboard

A good-looking sidebar in one config file.

Show your players their health, ping, money, rank, kills and anything else, on a clean sidebar that never flickers. Pick one of the ready designs or write your own lines with colors and placeholders.

✅ Spigot, Paper & Purpur · 1.20 → 26.x · Vault & PlaceholderAPI optional

💬 Found a bug or have an idea? Tell us on Discord.

✨ Features

  • 🚫 No flickering. Lines are updated in place, never removed and re-added.
  • 🔢 Hidden red numbers on the right side (Paper & Purpur 1.20.3+).
  • 🎞️ Animated title: a list of frames that cycle as fast as you want.
  • 🌈 Colors: &a, &l… and hex &#RRGGBB for gradients.
  • 💰 Real money and rank from Vault: works with EssentialsX, CMI, LuckPerms and others.
  • 🔌 PlaceholderAPI: use any %placeholder% from any plugin.
  • 🏷️ Plays nice with nametag plugins: prefixes, name colors and below-name health stay visible while the sidebar is shown.
  • 🌍 Disabled worlds: hide the board in minigames or lobbies.
  • 👤 /sb toggle: players can hide their own board, and it's remembered after a restart.
  • 🎨 5 ready designs in the config: minimal, modern, PvP, boxed and gradient.

🏷️ Placeholders

Placeholder Shows
{player} {displayname} Player name
{hp} {max_hp} {food} Health, max health, hunger
{level} {exp} XP level, % to next level
{ping} Player ping
{tps} {tps_color} Server TPS and a matching color
{online} {max_online} Players online
{world} {x} {y} {z} World and coordinates
{time} {date} Real time and date (your own format)
{kills} {deaths} {playtime} Player statistics
{money} Balance (Vault + economy plugin)
{rank} Primary group (Vault + permission plugin)
%anything% Any PlaceholderAPI placeholder

📜 Commands

Command Description Permission
/sb toggle Show or hide your scoreboard scoreboard.toggle
/sb reload Reload the config scoreboard.reload

Aliases: /scoreboard, /simplescoreboard

🔑 Permissions

Permission Description Default
scoreboard.use See the scoreboard everyone
scoreboard.toggle Use /sb toggle everyone
scoreboard.reload Reload the config OP
scoreboard.update Update notifications on join OP

⚙️ Configuration

scoreboard:
  title: "&6&lMY &e&lSERVER"
  animated-title:
    enabled: false
    interval-ticks: 5
    frames: ["&6&lMY SERVER", "&e&lMY SERVER", "&f&lMY SERVER"]
  update-interval: 20
  lines:
    - "&7&m                    "
    - "&e⚡ &fPlayer: &b{player}"
    - "&f★ &fRank: &e{rank}"
    - "&c❤ &fHealth: &a{hp}&7/&a{max_hp}"
    - "&6$ &fMoney: &a{money}"
    - "&a🌐 &fPing: &e{ping}ms"
    - "&7play.example.com"

auto-enable: true
hide-numbers: true
sync-main-scoreboard-teams: true
disabled-worlds: [example_minigame]

📦 Installation

  1. Put SimpleScoreboard.jar in your plugins/ folder.
  2. Optional: install Vault (for {money} and {rank}) and PlaceholderAPI.
  3. Restart, then edit plugins/SimpleScoreboard/config.yml and run /sb reload.

📋 Compatibility
Servers Spigot, Paper, Purpur
Versions 1.20 → 26.x (one jar)
Java 17+
Optional Vault, PlaceholderAPI

Folia has no scoreboard API, so SimpleScoreboard turns itself off there with a clear message.

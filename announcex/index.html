📢 AnnounceX

Get every player's attention: center of the screen, boss bar, action bar or chat.

Announce events, restarts and votes in the way that fits, for exactly as long as you want. Set up automatic rotations so your server advertises itself, with sounds, particles and full color support.

✅ Spigot, Paper, Purpur & Folia · 1.20 → 26.x · zero dependencies

💬 Found a bug or have an idea? Tell us on Discord.

✨ Four ways to announce

Type Command Where it shows
🎬 Title /announcetitle [time] <title|subtitle> Big text in the center of the screen
🟪 Boss bar /announcebossbar [time] <message> A bar at the top that counts down
⬇️ Action bar /announceactionbar [time] <message> Above the hotbar
💬 Chat /announcechat <message> In chat, | makes a new line

Examples

/announcetitle 10s &6&lEVENT!|&7Starts in 5 minutes at /warp arena
/announcebossbar 5m &dDouble XP weekend is live!
/announceactionbar 30s &aSpawn PvP is now ON
/announcechat &cServer restart in 5 minutes!|&7Save your stuff.

Time format: 30s, 5m, 1h, 1h30m, 2d. Leave it out to use the default from the config.

🔁 Automatic announcements

Every type has its own rotation:

  • its own interval and message list,
  • in order or random,
  • min-players: stay quiet on an empty server.

Great for vote reminders, Discord links, store ads and rules.

🎨 Make it yours

  • Colors: &a, &l… and hex &#RRGGBB.
  • Placeholders: {player}, {online}, {max_online}.
  • Sounds for each type: Minecraft keys like entity.player.levelup, names like ENTITY_PLAYER_LEVELUP, or resource pack sounds.
  • Boss bar color and style: pink, blue, red, green, yellow, purple, white; solid or segmented.
  • Title timing: fade in, stay and fade out, plus particles.
  • Players who join while a boss bar is up see it too.

📜 Commands

Command Aliases Description
/announcetitle /atitle, /at Title announcement
/announcebossbar /aboss, /ab Boss bar announcement
/announceactionbar /aactionbar, /aab Action bar announcement
/announcechat /achat, /ac Chat announcement
/announcex list /anx What is on screen right now
/announcex clear <titles|bossbars|actionbars|all> Remove announcements
/announcex reload Reload the config

⚙️ Configuration

title:
  fade-in: 10
  stay: 60
  fade-out: 10
  single-line-as: title      # or subtitle
  sound: { name: "entity.player.levelup", volume: 0.8, pitch: 1.2 }

bossbar:
  duration: 100
  color: PURPLE
  style: SOLID

chat:
  prefix: "&8[&6&lINFO&8] &f"

auto:
  min-players: 1
  bossbar:
    enabled: true
    interval-seconds: 180
    random-order: false
    messages:
      - "&d&l♥ &fHave fun on the server! &d&l♥"
      - "&c&l❤ &fJoin our Discord: &cdiscord.gg/example &c&l❤"

📦 Installation

  1. Put AnnounceX.jar in your plugins/ folder.
  2. Restart the server.
  3. Edit plugins/AnnounceX/config.yml and run /announcex reload.

Updating from 1.0? Your old config is moved to the new layout automatically. The /ax alias was removed (it clashed with AntiXray): use /announcex or /anx.

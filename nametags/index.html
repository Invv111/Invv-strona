🏷️ Nametags

Prefixes, gradients and a health bar: above heads, in TAB and in chat.

Nametags gives every player a custom prefix, suffix and name color that show up everywhere at once: above their head, in the TAB list and in chat. RGB hex and smooth gradients included, plus a live HP display under player names.

✅ Paper, Purpur & Folia · 1.20.6 → 26.x · LuckPerms optional

💬 Found a bug or have an idea? Tell us on Discord.

✨ Features

  • 🎯 One format, three places. Prefix, name color and suffix show above heads, in TAB and in chat.
  • 🌈 RGB & gradients. Legacy codes (&a, &l), hex (&#FF5555) and multi-color gradients (&#FF0000&#00FF00Admin).
  • ❤️ Health under the name. A live <health> HP line under every player, updated 1 tick after damage or healing. Toggle it per player.
  • 💬 Clean chat format. <Steve> hi becomes Prefix Steve Suffix: hi, and colors never bleed into the message.
  • ✂️ Auto-spacing. A missing space after a prefix or before a suffix is added for you.
  • 🔗 LuckPerms sync. Pull prefixes and suffixes from LuckPerms groups once, or keep them synced automatically every 5 seconds.
  • 🤫 Silent changes. Change someone's tag without notifying them.
  • 💾 Persistent. Everything is saved in data.yml and survives restarts.
  • ⌨️ Full tab completion for players, subcommands and colors.

📜 Commands

Command Description
/nametag <player> prefix <text> Set a prefix (player is notified)
/nametag <player> silentprefix <text> Set a prefix silently
/nametag <player> rgbprefix <gradient> Set a gradient prefix, e.g. &#FF0000&#00FF00Owner
/nametag <player> suffix <text> Set a suffix
/nametag <player> silentsuffix <text> Set a suffix silently
/nametag <player> rgbsuffix <gradient> Set a gradient suffix
/nametag <player> nickcolor <color> Name color: red, blue, gold, aqua…
/nametag <player> subtitle <on/off> Toggle the HP line under the name
/nametag <player> <category> reset Reset prefix, suffix or nickcolor
/nametag <player> luckperms-sync Copy prefix/suffix from LuckPerms once
/nametag luckperms-autosync Toggle automatic LuckPerms sync
/nametag reload Reload the config

🔑 Permissions

Permission Description Default
nametags.use Change prefixes, suffixes, colors and HP display OP
nametags.admin Reload and LuckPerms autosync OP

📦 Installation

  1. Put the jar in your plugins/ folder.
  2. Restart the server.
  3. Try /nametag <you> rgbprefix &#FF0000&#FFAA00Owner.

🎲 QuickRTP

Fast, safe and lag-free random teleport for your server. Type /rtp and you land in a random safe spot in the wild. No lava, no ocean, no void, no lag.

✨ Features

  • 🛡️ Safe landing. Never drops you into lava, water, fire, cactus, magma, powder snow or the void
  • ⚡ No lag. Chunks load asynchronously, so the main thread never freezes
  • 🌐 Folia support. Every block check runs on the region that owns the chunk
  • 🔥 Nether & End. Finds a spot under the nether roof and only lands on End islands
  • 🎯 Ring search. Picks a spot between min-radius and max-radius, always inside the world border
  • 🗺️ Per-world settings. Set the radius and center per world, or turn RTP off in a world
  • ⏳ Cooldown & warmup. Action-bar countdown; moving cancels the teleport
  • 👮 Admin tools. /rtp <player> [world] from chat or console
  • 👋 First join RTP. Optionally scatter brand-new players
  • 🎨 Fully configurable. Every message, the title and the sound, with & color codes
  • 🌊 Biome blacklist. For example, skip oceans or deep dark
  • 📦 No dependencies. Lightweight, a single jar of about 20 KB

📜 Commands

Command Description
/rtp Random teleport in your current world
/rtp <world> Random teleport into a specific world
/rtp <player> [world] Random teleport another player
/rtp reload Reload the config

Aliases: /wild, /wilderness, /randomtp

🔑 Permissions

Permission Description Default
quickrtp.use Use /rtp everyone
quickrtp.world Choose a world op
quickrtp.others Teleport other players op
quickrtp.bypass.cooldown No cooldown op
quickrtp.bypass.delay No warmup op
quickrtp.reload Reload the config op

⚙️ Config preview

cooldown: 60          # seconds between uses
delay: 3              # warmup, moving cancels it
max-attempts: 25
rtp-on-first-join: false
fallback-world: "world"

default:
  enabled: true
  min-radius: 300
  max-radius: 5000
  use-border-center: true

worlds:
  world_nether:
    max-radius: 2000
  spawn_lobby:
    enabled: false    # /rtp here sends players to fallback-world

🔒 AntiXray

Lightweight. Powerful. Zero dependencies.

AntiXray is a lightweight anti-X-ray plugin for Paper and Purpur 1.20–26.x. It protects your server by hiding valuable ores, containers, and spawners from X-ray mods, texture packs, and cheat clients — without modifying your world data.

No ProtocolLib. No extra plugins. Just one JAR.

⚠️ Warning

If you encounter any issues with the plugin, please report them on our Discord server.

✨ Features

  • 🛡️ Advanced Anti-Xray Protection — Hide valuable blocks from X-ray users without changing your actual world.
  • ⚡ High Performance — Optimized processing with minimal impact on server performance.
  • 🎭 Fake Ore Mode — Make X-ray users see fake ores scattered throughout solid stone.
  • 👁️ Proximity Hider — Keep containers, spawners, vaults, and exposed ores hidden until players get close enough.
  • 🔍 Smart Reveal System — Reveal ores immediately when mining, explosions, pistons, falling blocks, and other supported events expose them.
  • 🌍 All Dimensions Supported — Protect the Overworld, Nether, and End.
  • 🎮 In-Game GUI — Configure important settings directly in-game using /ax.
  • 📊 Live Performance Monitor — Track chunk processing, hidden blocks, revealed blocks, and processing times.
  • 🔧 Automatic Engine Selection — Automatically selects the best protection engine for your server version.
  • 🔑 Staff Bypass — Allow trusted staff to see the real, unmodified world.
  • 💬 Customizable Messages — Edit plugin messages using MiniMessage formatting.
  • 📦 Zero Dependencies — No ProtocolLib or other plugins required.

🎮 Player Experience

AntiXray is designed to protect your server without affecting legitimate players.

  • X-ray users see stone. Ores hidden behind solid blocks are replaced with appropriate stone-like blocks, such as stone, deepslate, netherrack, or end stone.
  • Ores reveal naturally. When a player mines a block and exposes an ore, the real block becomes visible to nearby players.
  • Containers stay hidden. Chests, barrels, shulker boxes, spawners, and other supported blocks remain concealed until the player comes within the configured distance.
  • Walls provide real protection. Optional ray-tracing ensures hidden blocks cannot be revealed through walls.
  • Every dimension is covered. Protect valuable resources in the Overworld, Nether, and End.
  • Legitimate gameplay stays unchanged. Players can mine and explore normally without unnecessary visual obfuscation of visible blocks.

🛡️ Protection Engines

AntiXray supports two protection engines and automatically selects the most suitable option for your server.

📡 Packet Engine

Available on supported Paper versions, including Paper 1.20.5+ and 26.x.

  • Removes hidden block information from chunk packets before they reach the client.
  • Prevents clients and X-ray mods from receiving the real data of concealed blocks.
  • Processes protection on the network thread to reduce main-thread overhead.
  • Uses an automatic self-test to verify the engine on a real chunk.

🔄 API Engine

Used as a fallback for Paper 1.20–1.20.4.

  • Obfuscates hidden blocks after the chunk is sent.
  • Provides compatibility with older supported server versions.
  • Is selected automatically when appropriate.

⚙️ Protection Modes

Mode 1 — Hide

Blocks covered on all six sides are replaced with the appropriate stone-like material. This prevents X-ray users from seeing valuable ores through solid blocks.

Mode 2 — Fake Ores

Includes everything from Hide mode, with an additional layer of deception: fake ores are scattered throughout solid stone according to your configured density.

X-ray users may see ores everywhere, making it much harder to distinguish real deposits from fake ones.

👁️ Proximity Hider

AntiXray can hide the following blocks until players approach them:

  • Chests and trapped chests
  • Barrels
  • Ender chests
  • Shulker boxes
  • Mob spawners
  • Trial spawners
  • Vaults
  • Ores exposed in caves

Available options include:

  • Configurable detection distance
  • Optional line-of-sight checks using ray-tracing
  • Configurable check intervals
  • Selectable blocks to protect
  • Optional hiding of exposed ores

The plugin also strips hidden block entity data from relevant packets, preventing clients from receiving concealed container information.

💥 Smart Reveal System

Hidden ores are updated when they become exposed through supported world events, including:

  • Mining
  • Explosions
  • Pistons
  • Falling sand and gravel
  • Burning blocks

The update radius is configurable, and ores near chunk borders are handled correctly.

🔑 Bypass Permission

Trusted staff members can bypass all obfuscation using:

antixray.bypass

Players with this permission see the real, unmodified world.

🖥️ In-Game GUI & Live Monitor

Interactive Settings Panel

Run /ax to open the in-game configuration panel.

Configure important settings with a few clicks, including:

  • Protection enabled/disabled
  • Protection mode
  • Fake ore density
  • Protection engine
  • Reveal radius
  • Proximity hider
  • Detection distance
  • Ray-tracing
  • Cave ore protection
  • Check interval
  • Debug mode
  • Per-world protection

Changes are saved to config.yml and applied immediately.

📊 Live Performance Monitor

Use /ax monitor to enable the live performance display.

Monitor information such as:

  • Chunks processed per second
  • Processing time per chunk
  • Hidden blocks per second
  • Revealed blocks per second

Choose between a boss bar and an action bar display.

💬 Customizable Messages

All plugin messages are stored in messages.yml and support MiniMessage, including gradients, hover events, and clickable text.

Customize the plugin's messages to match your server's style.

⌨️ Commands & Permissions

Command permission: antixray.admin
Default permission level: OP

Command Description
/ax Open the settings GUI
/ax gui Open the settings GUI
/ax status Display the plugin state, active engine, mode, proximity hider, and protected worlds
/ax stats Display performance statistics, including processed chunks, average processing time, hidden/revealed blocks, and errors
/ax monitor Toggle the live boss bar/action bar monitor
/ax toggle Enable or disable protection
/ax selftest [world] Test the protection engine on your current chunk or a world's spawn chunk
/ax reload Reload config.yml and messages.yml without restarting
/ax resetstats Reset performance statistics

Permissions

Permission Description
antixray.admin Access the GUI and all plugin commands
antixray.bypass See real ores and blocks without obfuscation

⚙️ Configuration

AntiXray offers flexible configuration options for adapting protection to your server.

Main Options

Setting Description
hidden-blocks Defines which blocks should be hidden. Supports wildcards such as *_ORE.
engine.type Selects auto, packet, or api.
engine.mode Selects Mode 1 (Hide) or Mode 2 (Fake Ores).
fake-ore-density Controls the density of fake ores.
replaceable-blocks Defines which blocks can be replaced during obfuscation.
proximity Configures detection distance, ray-tracing, check intervals, exposed ore hiding, and protected blocks.
update-radius Controls how far nearby blocks are checked when ores become exposed.
disabled-worlds Specifies worlds where protection is disabled.
monitor.style Configures the live monitor display style.
debug Enables additional diagnostic information.

Additional details and defaults are available in the generated configuration file.

Version compatibility: Block names that do not exist in your server version are automatically skipped.

Automatic migration: Older configuration files are migrated automatically, and a backup is kept.

⚡ Performance

AntiXray is designed to provide strong protection while keeping overhead low.

  • Packet-based obfuscation runs on the network thread.
  • Empty chunk sections are skipped entirely.
  • Precomputed lookup tables optimize block processing.
  • Per-player tracking is cleaned up when chunks unload or players leave.
  • If an error occurs, the affected packet is sent unchanged and the error is recorded in /ax stats.
  • Players are not kicked because of internal processing errors.

Reported benchmark: Approximately 0.3–0.5 ms per chunk in our tests. Actual performance depends on server hardware, world conditions, and configuration.

📦 Requirements

  • Server software: Paper, Purpur, or another compatible Paper fork
  • Minecraft versions: 1.20–26.x, subject to server software compatibility
  • Java: Java 17+ or the version required by your server
  • Dependencies: None

Not supported: Folia, plain Spigot, and CraftBukkit.

🚀 Installation

  1. Download AntiXray-4.0.0.jar.
  2. Place the JAR file in your server's plugins/ folder.
  3. Restart your server.
  4. The plugin will automatically generate config.yml and messages.yml.
  5. Run /ax in-game to open the configuration panel.
  6. Customize your settings and enjoy improved server protection!

⚠️ Important: Disable Built-in Paper Anti-Xray

If Paper's built-in Anti-Xray is enabled in config/paper-world-defaults.yml, disable it to avoid conflicts. AntiXray will warn you in the console if it detects this configuration.

🔧 Editing Configuration Manually

You can also edit:

plugins/AntiXray/config.yml

After making changes, run:

/ax reload

No server restart is required for configuration reloads.

AdminEssentials

AdminEssentials is a comprehensive administration plugin that combines powerful moderation tools with fun troll commands. It provides everything you need to manage your Minecraft server effectively while keeping things entertaining.

🛡️ AdminEssentials

All-in-one administration, moderation and troll plugin. One lightweight jar with 90+ commands: moderation, vanish, freeze, reports, warnings, staff chat, warps, maintenance mode, an update checker, a Discord webhook, and the troll commands everyone loves. 😈

✅ Paper · Folia · Purpur · Pufferfish · Spigot · Bukkit ✅ Minecraft 1.20 → 26.3 in one jar ✅ No dependencies · English 🇬🇧 and Polish 🇵🇱 included

⚠️ Found a bug or have an idea? Report it on our Discord!

✨ What's new in 2.0

  • 🧵 Folia support: real region-threading support, not just a flag in plugin.yml.
  • 🔔 Update notifications: admins get a clickable Modrinth link on join when a new version is out.
  • ⚖️ Moderation suite: offline and temporary bans, IP bans, warnings with automatic punishments, punishment history, alt detection, reports.
  • 💬 Chat tools: staff chat, private messages, social spy, command spy, slow mode, anti-spam, word filter.
  • 🌍 Languages and config: every message can be edited, plus a Discord webhook and an action log.

⚖️ Moderation

Command What it does
/ban <player> [time|perm] [reason] [-s] Ban online or offline players
/tempban · /unban · /banlist · /checkban Temporary bans, unban, ban list, ban info
/banip <player|ip> · /unbanip Ban a player's IP address
/mute · /tempmute · /unmute · /mutelist Mutes (also block /msg, /me, ...)
/kick · /kickall Kick with a custom kick screen
/warn · /warnings · /clearwarns Warnings with automatic punishments (3 = mute, 5 = tempban, ...)
/history <player> Full punishment history
/alts <player> Accounts sharing an IP, plus a join alert for banned alts
/freeze · /unfreeze Lock a player in place: no moving, building, fighting or commands
/report · /reports Players report cheaters, staff click to teleport

🤫 Add -s to any punishment to make it silent (only staff see it). ⏱️ Times: 30s 10m 1h30m 7d 2w 1mo 1y perm

👻 Vanish 2.0

  • Hidden from players, visible to other staff
  • Stays on after you rejoin, with silent join and quit
  • Optional fake "left the game" message
  • Action bar reminder, no item pickup, mobs ignore you

💬 Chat

  • /staffchat (/sc), or start a message with #
  • /msg · /r · /socialspy · /commandspy
  • /mutechat · /clearchat · /slowmode <sec>
  • Anti-spam, anti-caps, word filter
  • /broadcast [-t] (with a title) and an automatic announcer
  • Admin [Admin] prefix in chat and tab, configurable chat format with &#RRGGBB hex colours

🛠️ Admin tools

  • /gm /gmc /gms /gma /gmsp · /fly · /heal · /feed · /god · /speed · /flyspeed · /walkspeed
  • Use * to target everyone: /heal *, /gm 1 *
  • /invsee (read-only by default) · /enderchest · /workbench · /repair [all] · /more · /hat · /head · /nick
  • /kill · /clear · /extinguish · /ping · /sudo · /whois · /seen · /near · /staff
  • /serverinfo: TPS, memory, uptime, chunks and entities per world
  • /maintenance: only staff can join, with a custom MOTD

🗺️ Teleport and world

  • /tp <player> [player] · /tp x y z · /tppos (with ~) · /tphere · /tpall
  • /back (also after death) · /top · /spawn · /setspawn
  • /setwarp · /warp · /warps · /delwarp, with optional per-warp permissions
  • /time · /day · /night · /weather · /sun · /rain · /thunder (per world, with duration)

🎭 Troll commands

/rocket 🚀 · /burn 🔥 · /explode 💥 (no block damage) · /smite ⚡ · /launch 🎪 · /slap 👋 · /fakeop 😈 · /fakejoin · /fakequit

🔔 Update checker

AdminEssentials checks the Modrinth API for new versions. Admins with adminessentials.update.notify get a clickable download link and the changelog when they join. Run /ae update to check right away.

⚙️ Configuration

  • config.yml: chat, vanish, freeze, warnings, spawn, announcer, webhook, disabled-commands
  • lang/messages_en.yml and lang/messages_pl.yml: edit any message or add your own language
  • /ae reload: reload without a restart
  • Discord webhook: bans, mutes, kicks, warnings, reports, helpop
  • logs/actions.log: every staff action with a timestamp

🔑 Permissions

  • adminessentials.*: everything (ops have this by default)
  • adminessentials.mod: a ready-made moderator kit (moderation, vanish, teleports, chat tools)
  • <permission>.others: use a command on other players, e.g. adminessentials.heal.others
  • <permission>.exempt: protection from being banned, muted, kicked, frozen or trolled
  • Players can use /helpop, /msg, /r, /report, /spawn, /warnings, /ping and /staff by default

Full list: /ae help in game.

📦 Installation

  1. Drop AdminEssentials-2.0.0.jar into plugins/
  2. Restart the server
  3. Optional: set language: pl in config.yml, then run /ae reload

Upgrading from 1.0? Warps, bans, mutes and the chat lock are imported automatically.

PS: Use troll commands responsibly! 😇 PPS: Vanish + troll commands = endless fun! 😈

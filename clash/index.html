⚔ Clash

Combat tag & anti combat-log. Fight fair, or log out and die.

Paper · Folia · Purpur · Minecraft 1.20 → 26.x · zero dependencies · one jar

You're winning a fight. Your opponent is on two hearts. They press Disconnect.

With Clash, that's the worst decision they'll make all day. Hit another player and you're both in combat for 15 seconds: a boss bar counts down, escape commands stop working, and anyone who logs out before it ends dies on the spot, dropping everything for the winner.

✨ Features

⚔ Combat tag

  • Hit a player (sword, bow, trident, splash potion, TNT, lingering cloud, even your tamed wolf) and both of you are tagged
  • Every hit resets the timer
  • Hits cancelled by WorldGuard, team plugins or PvP toggles never tag anyone
  • Creative/spectator players, NPCs (Citizens & co.) and disabled worlds are ignored
  • Optional: tag players hurt by mobs too

📊 Clean, live display

  • Boss bar with your opponent's name and a smooth countdown that turns yellow when the fight is nearly over
  • Optional action bar timer
  • Subtle sounds when you enter and leave combat

☠ Combat-log punishment

  • Logging out while tagged kills you: items drop where you stood
  • Server-wide broadcast + a harmless lightning strike for drama
  • Run any console commands (eco take <player> 100, ban, …)
  • Kicks (staff, anti-cheat) are not punished by default; timeouts (pulling the cable) are
  • The vanilla death message is replaced by Clash's broadcast so chat stays clean

🚫 No escape

  • Blocked commands: /spawn, /home, /tpa, /rtp, /warp, /back and more out of the box
  • Aliases and namespaces are caught automatically (/essentials:home, /h, …)
  • Blacklist or whitelist mode
  • Ender pearls: longer cooldown (default 8 s) or blocked completely
  • Elytra gliding is cancelled
  • /fly is switched off and given back when the fight ends
  • Teleports from commands and plugins are cancelled

🛠 For admins & developers

  • /clash tag, /clash untag <player|*>, /clash list, /clash reload
  • Full MiniMessage support (gradients, hex colors, click events)
  • English & Polish included, add any language as a file
  • PlaceholderAPI: %clash_in_combat%, %clash_time%, %clash_opponent%, %clash_status%
  • Developer API: ClashAPI.isInCombat(player) plus PlayerCombatTagEvent, PlayerCombatUntagEvent and PlayerCombatLogEvent (cancellable)
  • Native Folia support: every player is handled on their own region thread
  • Update checker (can be turned off)

📦 Installation

  1. Drop Clash-x.y.z.jar into plugins/
  2. Restart the server
  3. Tweak plugins/Clash/config.yml and run /clash reload

That's it. No dependencies, no database.

💬 Commands

Command Description Permission
/clash Your combat status clash.command (everyone)
/clash tag <player> [seconds] Put a player in combat clash.admin
/clash untag <player|*> Take players out of combat clash.admin
/clash list Everyone currently fighting clash.admin
/clash reload Reload config and messages clash.admin

Aliases: /combat, /ct, /combattag

🔑 Permissions

Permission Default Description
clash.command everyone Check your own status
clash.admin op Admin commands
clash.notify op Update notifications
clash.bypass nobody Never get tagged
clash.bypass.commands nobody Use blocked commands in combat
clash.bypass.restrictions nobody Keep pearls, elytra, fly and teleports
clash.bypass.punishment nobody Log out in combat without dying

Bypass permissions are not given to ops automatically, so staff fight by the same rules unless you say otherwise.

⚙ Configuration

config.yml (click to expand) 
language: en
update-checker: true

tag:
  duration: 15
  mob-damage: false
  pet-damage: true
  ignore-creative: true
  untag-killer-on-kill: false
  disabled-worlds:
    - example_lobby

display:
  bossbar:
    enabled: true
    color: RED
    ending-color: YELLOW
  actionbar:
    enabled: false
  sounds:
    enabled: true

combat-log:
  kill: true
  broadcast: true
  lightning: true
  punish-kicks: false
  punish-timeouts: true
  commands: []

commands:
  mode: blacklist
  list: [spawn, home, homes, sethome, tpa, tpahere, tpaccept, warp, back, rtp, wild, hub, lobby, kit, enderchest, ec, fly, gamemode, vanish]

restrictions:
  ender-pearl:
    block: false
    cooldown: 8
  block-elytra: true
  disable-flight: true
  blocked-teleports: [COMMAND, PLUGIN, SPECTATE]

✅ Tested

Every release is tested automatically on real servers with bot players: Paper 1.20.6, 1.21.4, 1.21.11, 26.1.2 and Folia 1.20.6. The tests cover tagging, the timer and expiry, blocked commands and teleports, death, kicks, the combat-log kill with drops, broadcast and commands, and every admin command. It was also played by hand on a 26.1.2 client.

  • PlayerHeadDrop: a trophy for the winner
  • Tpa & SetHome: blocked automatically during fights

🔍 Better Zoom

Zoom in smoothly. Aim steadily. Scroll for more.

Hold C to zoom in with a smooth animation. Scroll the mouse wheel to go further, all the way to 100x. Your mouse slows down the closer you zoom, so the crosshair stays steady even at long range.

✅ Fabric · Minecraft 26.1 → 26.3 · client-side only

💬 Found a bug or have an idea? Tell us on Discord.

✨ Features

  • 🎞️ Smooth zoom: a soft zoom-in / zoom-out animation instead of a jump cut.
  • 🖱️ Scroll to zoom: mouse wheel zooms further in or out while zooming. Your hotbar slot doesn't change.
  • 🎯 Steady aim: the mouse gets slower the more you zoom in, like a real scope.
  • 🎬 Cinematic camera (optional): extra smooth camera while zooming, your normal setting comes back after.
  • 🔁 Hold or toggle: hold C (default), or press once to zoom and again to stop.
  • ⚙️ Configurable: zoom strength, animation speed, max zoom and more.
  • ⌨️ Rebindable in Options → Controls → Key Binds → Zoom Mod.
  • 🪶 Tiny & client-side: works on any server.

⚙️ Configuration

config/zoom.json is created on the first start:

{
  "mode": "hold",
  "zoomLevel": 4.0,
  "smoothZoom": true,
  "smoothSpeed": 0.15,
  "scrollZoom": true,
  "maxZoom": 100.0,
  "resetScrollOnRelease": true,
  "reduceSensitivity": true,
  "cinematicCamera": false
}
Option What it does
mode hold or toggle
zoomLevel How much C zooms in (4.0 = 4x)
smoothZoom / smoothSpeed The zoom animation and its speed
scrollZoom / maxZoom Mouse wheel zoom and its limit
resetScrollOnRelease Forget the wheel zoom when you let go of C
reduceSensitivity Slower mouse while zoomed
cinematicCamera Smooth cinematic camera while zoomed

📦 Installation

  1. Install Fabric Loader and Fabric API.
  2. Put BetterZoom.jar in your mods folder.
  3. Start the game and hold C.

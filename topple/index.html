🌲 Topple

Trees that really fall. Chop one log and the whole tree tips over, crashes to the ground and drops its loot where it lands.

Not a teleporting pile of items: a real, smooth falling animation, with the crown swinging down, a bounce on impact and a burst of leaves. Server-side only. No resource pack, no mods, no dependencies. Paper and Folia, 1.20 → 26.x.

✨ Features

🪓 Fell the whole tree

  • Hit the bottom log with an axe and every log, leaf, vine and cocoa pod above it comes down together.
  • Cut halfway up and only the top falls, leaving a stump behind.
  • Branches are found too (acacia, cherry, mangrove, jungle), and 2×2 trees like dark oak, jungle and giant spruce fall as one.
  • Sneak to take a single log, the vanilla way. /topple toggle turns felling off for yourself.

🎬 A real falling animation

  • The tree turns around its stump like a real trunk: slow at first, then faster, then thud.
  • It falls away from you, never on your head.
  • It lies flat on level ground, leans on walls and hills, and tips over the edge of a cliff.
  • Creaking wood when it starts, a crash and leaf debris when it lands, a short bounce, then it breaks apart into loot.
  • Built on vanilla block displays with client-side interpolation, so it is smooth even when the server isn't, and works for every player without a resource pack.

🎁 Loot where it lands

  • Logs, saplings, apples and sticks drop on the ground where each block landed. Walk along the fallen trunk and pick it all up.
  • Prefer it simple? Send drops to the stump or straight into the inventory.
  • Real vanilla drops: Fortune on leaves, Silk Touch, shears behaviour and loot tables all still apply.

🌱 Auto-replant

  • A sapling pops back where the trunk stood, with a little sparkle. 2×2 trees get four, so dark oak grows back.
  • Fungi go back on nylium, mangrove propagules on mud.
  • Optionally the sapling must come from the tree's own drops, so nothing is created out of thin air.

🏠 Never fells your house

  • Topple remembers every log a player places, inside the chunk itself (no database). Log walls, cabins and roofs are never felled.
  • Trees need natural leaves. Player-placed leaves never decay, so a log pillar with decorative leaves stays put.
  • Two trees touching? Only the one you chopped falls. Its neighbour keeps its trunk and its crown.
  • Huge builds are safe too: anything over max-logs is chopped one log at a time.

🛡️ Plays nice with your server

  • Protection aware: WorldGuard, GriefPrevention, Lands, Towny and other claim plugins are asked about every block. If any is protected, only the log you hit breaks.
  • CoreProtect logs every felled block, so tree griefing can be rolled back.
  • Axe durability is charged per log (Unbreaking counts), and the axe is never broken by a tree: if it can't take it, you chop log by log.
  • Hunger cost per log, vanilla mining statistics, bee nests release their bees.
  • Folia native: every block, entity and drop is handled by the region that owns it.

🌍 Every tree in the game

Oak, spruce, birch, jungle, acacia, dark oak, mangrove, cherry, pale oak, azalea trees, crimson and warped fungi and huge mushrooms. Wood types come from Minecraft's own tags, so trees added in future updates work without a plugin update.

⌨️ Commands

Command Description Permission
/topple toggle Turn tree felling on or off for yourself topple.toggle
/topple stats Trees felled and logs chopped topple.use
/topple toggle <player> Toggle for someone else topple.admin
/topple stats <player> Someone else's stats topple.admin
/topple reload Reload config and messages topple.admin

Felling needs topple.use (on by default). Alias: /timber. topple.notify (op) tells admins about updates.

⚙️ Configuration

Everything is switchable, and /topple reload applies changes live:

activation: standing     # standing (sneak = one log), sneaking, always
require-axe: true
fall-direction: away     # or random
drops: landing           # landing, stump, inventory

tree:
  max-logs: 256
  leaves: fall           # fall, break, decay
  nether-trees: true
  huge-mushrooms: true

animation:
  enabled: true          # false = classic instant timber
  speed: 1.0             # 0.5 = slow motion
  settle-ticks: 30
  sounds:
    impact:
      - "minecraft:entity.zombie.break_wooden_door 0.9 0.6"

replant:
  enabled: true
  use-drops: true

durability:
  per-log: 1
  protect-axe: true

Plus per-world disabling, view range, particles, hunger cost and every sound. All messages use MiniMessage; English and Polish are included, and you can add your own lang/<name>.yml.

🧑‍💻 For developers

TreeFellEvent fires before a tree falls. Cancel it, read the logs and leaves that will fall, or change the direction:

@EventHandler
public void onFell(TreeFellEvent event) {
    if (event.getLogs().size() > 100) event.setCancelled(true);
    event.setDirection(new Vector(1, 0, 0)); // always fall east
}

📦 Compatibility
Servers Paper, Folia, Purpur and other Paper forks
Versions 1.20 → 26.x
Java 17+ (21+ for 1.20.5 and newer, as Minecraft itself requires)
Dependencies None. PlaceholderAPI optional
Clients Vanilla. Nothing to install

Plain Spigot is not supported: Topple uses Paper's scheduler and item APIs.

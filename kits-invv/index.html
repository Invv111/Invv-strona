🎁 Kits

The simplest way to give your players kits. Put items in your inventory, type one command, done. Clean GUI, cooldowns, one-time kits, previews and a starter kit for new players. No setup headaches, no dependencies.

✨ Features

  • 📦 Create kits in seconds – /createkit <name> [cooldown] saves your whole inventory, armor and offhand included
  • 🖱️ Beautiful GUI – /kit opens a menu showing every kit and its status:
    • 🟢 Available
    • 🔴 Available in: 2h 15m
    • ⛔ Already claimed / No access
  • 👀 Kit preview – right-click any kit to see exactly what's inside before claiming
  • ⏱️ Flexible cooldowns – 30m, 1h, 1d12h, 7d… or 0 for none
  • 🎟️ One-time kits – use -1 as the cooldown and the kit can be claimed only once, ever
  • 🛡️ Auto-equip armor – armor goes straight onto empty armor slots, shields into the offhand
  • 🎒 Nothing gets lost – items that don't fit are dropped at the player's feet
  • 🌱 Starter kit – new players automatically get a kit on their first join
  • 🎁 Give kits to others – /kit <name> <player> from chat or console (great for votes, crates, events)
  • 🔐 Optional per-kit permissions – kits.kit.<name>
  • 💾 Persistent – cooldowns survive restarts and reloads
  • 🎨 Every message is configurable – full & color code support
  • ⚡ Lightweight & Folia ready – no dependencies, no repeating tasks, nothing running in the background
  • 🌍 1.20 → 26.x – one jar works on Paper, Purpur and Folia from 1.20 up to the latest version

📜 Commands

Command Description Permission
/kit Open the kits menu –
/kit <name> Claim a kit – (or kits.kit.<name>)
/kit <name> <player> Give a kit to a player (no cooldown) kits.admin
/createkit <name> [cooldown] Create a kit from your inventory kits.admin
/delkit <name> Delete a kit kits.admin
/kit reload Reload config and kits kits.admin

Tip: the item you hold in your main hand while running /createkit becomes the kit's icon in the menu.

🔑 Permissions

Permission Description Default
kits.admin Create, delete, give kits, reload OP
kits.bypass.cooldown Ignore all cooldowns OP
kits.kit.<name> Access to a kit (only when require-permission: true) –
kits.kit.* Access to all kits OP

⚙️ Configuration

# Require kits.kit.<name> to claim a kit
require-permission: false

# Kit given on a player's first join ("" = disabled)
first-join-kit: "start"

# Menu title
menu-title: "&8Kits"

Messages are in English by default.

All messages and menu texts can be changed in config.yml.

🚀 Quick start

  1. Drop Kits.jar into your plugins folder and restart the server
  2. Fill your inventory with starter gear
  3. Run /createkit start 1d
  4. Done – new players get it on first join, everyone else can claim it daily with /kit

🧪 Quality

Kits is covered by 18 automated tests: claiming, cooldowns, one-time kits, permissions, full inventories, GUI clicks, reloads and invalid input. It is also tested on real servers: Paper 1.20.1, 1.20.6, 1.21.11, 26.3 and Folia 1.20.1, 26.3.

📋 Requirements

  • Paper, Purpur or Folia 1.20 – 26.x (one jar for all versions)
  • Java 17+ (whatever your server version needs)

🏪 ShopPlugin

Put a sign on a chest. Now it's a shop.

Players sell and buy items from each other with real money. Write four lines on a sign, fill the chest, done. No GUIs to learn, no commands for customers: right-click to buy, left-click to sell.

✅ Spigot, Paper, Purpur & Folia · 1.20 → 26.x · works with any Vault economy

💬 Found a bug or have an idea? Tell us on Discord.

🛠️ Make a shop in 10 seconds

Place a chest (or barrel / shulker box), put a sign on it and write:

Line What to write Example
1 [Shop] [Shop]
2 Amount per trade 16
3 Buy price : sell price B 10:S 5
4 The item, or ? for the item in your hand diamond

The sign turns into a shop right away:

[Shop]
16
B 10:S 5
Diamond

Only want to sell? Write B 10. Only want to buy from players? Write S 5.

✨ Features

💰 Real trading

  • Right-click the sign to buy, left-click to sell, sneak + click to see the price and stock.
  • Money goes straight to the shop owner, even when they're offline.
  • Works with EssentialsX, CMI and any other economy plugin that supports Vault.
  • Owners get a message when someone trades with them, and when the shop is empty or full.

👑 Admin shops

  • Write [AdminShop] (permission shop.admin) for a server shop with unlimited stock. Money comes from and goes to the server.
  • Perfect for a spawn market or a sell-all point.

🛡️ Protection built in

  • Only the owner can open the shop chest or break the chest and the sign.
  • Hoppers can't pull items out of a shop.
  • Explosions (TNT, creepers, beds) can't destroy shops.
  • Nobody can put a chest next to yours to turn it into a double chest they can open.
  • Shop signs can't be edited after they're made.

📦 Containers

Chests, double chests, trapped chests, barrels and shulker boxes.

🎨 Fully configurable

Every message can be changed in config.yml, with & colors and hex &#RRGGBB.

📜 Commands

Command Description Permission
/shop How to make a shop –
/shop reload Reload the config shop.reload

Aliases: /shops, /chestshop

🔑 Permissions

Permission Description Default
shop.create Create shops on your own chests everyone
shop.use Buy from and sell to shops everyone
shop.admin Admin shops, manage every shop OP
shop.reload Reload the config OP
shop.update Update notifications on join OP

⚙️ Configuration

sign:
  header: "&1[Shop]"
  admin-header: "&4[AdminShop]"

# Tell online shop owners when someone trades with them
notify-owner: true

protection:
  hoppers: true      # hoppers can't pull items out of shops
  explosions: true   # explosions can't destroy shops

messages:
  prefix: "&8[&6Shop&8] "
  bought: "&aYou bought &f{amount}x {item} &afor &f{price}&a."
  # ...every message can be changed

📦 Installation

  1. Install Vault and an economy plugin (EssentialsX, CMI…).
  2. Put ShopPlugin.jar in your plugins/ folder.
  3. Restart the server and make your first shop.

📋 Compatibility
Servers Spigot, Paper, Purpur, Folia
Versions 1.20 → 26.x (one jar)
Java 17+
Needs Vault + an economy plugin (for trading)

Updating from 1.0? Old 1.0 shops stay protected but no longer trade. Break the sign and make a new one.

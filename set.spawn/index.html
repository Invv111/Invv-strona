SetSpawn

Simple /spawn and /setspawn that feel immersive – a short countdown, disorienting effects and a cooldown.

Perfect for survival and RPG servers where teleporting shouldn't be instant and free. Drop it in, type /setspawn, and you're done – no setup needed.

✅ Supports 1.20 – 26.x · Spigot, Paper, Purpur & Folia

✨ Features

  • ⏳ Countdown before teleporting – 5 seconds by default, shown as a title and an action bar
  • 😵 Blindness & nausea while waiting, for an immersive teleport
  • 🚶 Cancels if you move or take damage – no more escaping fights with /spawn
  • ⏱️ Cooldown – 5 minutes by default, kept even if the player relogs
  • 🌀 Sound & particles on arrival
  • 🧭 Saves the exact spot – world, position and the direction you face
  • 👋 New players spawn at your spawn on their first join
  • 🏠 Lobby mode – send players to spawn every time they join, plus /hub and /lobby aliases
  • 🔁 Optional: respawn at spawn when the player has no bed
  • 🎨 Every message is editable, with & colors and &#RRGGBB HEX colors
  • 🔑 Real permissions with VIP bypasses – works with LuckPerms
  • ♻️ /setspawn reload – no restarts needed
  • 🔔 Update notifications for admins when a new version is out

📜 Commands

Command Description Default
/spawn (/hub, /lobby) Teleport to spawn Everyone
/spawn <player> Send a player to spawn instantly OP
/setspawn Set the spawn at your location OP
/setspawn reload Reload the config and messages OP

🔑 Permissions

Permission Description Default
setspawn.spawn Use /spawn Everyone
setspawn.spawn.others Use /spawn <player> OP
setspawn.set Use /setspawn OP
setspawn.reload Use /setspawn reload OP
setspawn.bypass.cooldown No cooldown OP
setspawn.bypass.delay Instant teleport, no effects OP
setspawn.update Get update notifications OP
setspawn.admin All of the above OP

⚙️ Configuration

teleport:
  delay: 5              # seconds before teleporting (0 = instant)
  cooldown: 300         # seconds between uses (0 = no cooldown)
  cancel-on-move: true
  cancel-on-damage: true

effects:
  blindness: true
  nausea: true

countdown:
  title: true
  action-bar: true

arrival:
  sound: true
  particles: true

spawn:
  set-world-spawn: true
  teleport-on-join: first-join   # first-join, always or never
  teleport-on-respawn: false

update-checker: true

All messages are in messages.yml.

🚀 Installation

  1. Put the jar in your plugins/ folder
  2. Start the server
  3. Stand where you want the spawn and type /setspawn

That's it!

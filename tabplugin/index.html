📶 TabPlugin

See who's lagging and who's AFK, right in the TAB list.

Every player gets their ping next to their name, colored from green to red. Players who stop moving are marked [AFK] automatically, and you get a custom TAB header and footer on top.

✅ Spigot, Paper, Purpur & Folia · 1.20 → 26.x · zero dependencies

💬 Found a bug or have an idea? Tell us on Discord.

✨ Features

📶 Ping in TAB

  • Steve [23ms] next to every name, updated every second.
  • Color coded: 🟢 good, 🟡 medium, 🟠 bad, 🔴 very bad. You choose the limits and colors.
  • Your own format: "{name} &8[{ping_color}{ping}ms&8]{afk}", with hex colors &#RRGGBB.

💤 AFK detection

  • Players are marked [AFK] after 5 minutes without activity (configurable).
  • Choose what counts as activity: moving, looking around, chat, commands, clicking.
  • /afk to go AFK yourself. Moving or chatting brings you back.
  • Optional chat messages: "Steve is now AFK" / "Steve is no longer AFK".
  • tabping.afk.exempt: staff who are never marked AFK.

🖼️ TAB header & footer

  • Text above and below the player list: server name, players online, TPS, your ping…
  • Placeholders {online}, {max_online}, {tps}, {ping}, {ping_color}, {world}.

⚡ Lightweight

  • One small task per player, no packet tricks, no dependencies.
  • Thread-safe on Folia.

📜 Commands

Command Description Permission
/afk Go AFK / come back tabping.afk
/tabping Everyone's ping and AFK status, plus TPS tabping.use
/tabping reload Reload the config tabping.use
/tabping toggle Turn the TAB changes on or off tabping.use

🔑 Permissions

Permission Description Default
tabping.afk Use /afk everyone
tabping.use /tabping, reload, toggle OP
tabping.afk.exempt Never marked AFK automatically –
tabping.update Update notifications on join OP

⚙️ Configuration

format: "{name} &8[{ping_color}{ping}ms&8]{afk}"
update-interval-ticks: 20

afk:
  time-seconds: 300
  text: "AFK"
  color: "GRAY"
  activity:
    look-around: true
    chat: true
    commands: true
    interact: true
  messages:
    now-afk: "&7* {player} is now AFK"
    no-longer-afk: "&7* {player} is no longer AFK"

ping:
  thresholds: { good: 50, medium: 100, bad: 150 }
  colors: { good: "GREEN", medium: "YELLOW", bad: "GOLD", very-bad: "RED" }

header-footer:
  enabled: true
  header: ["", "&b&lMY SERVER", "&7Online: &f{online}&7/&f{max_online}", ""]
  footer: ["", "&7Your ping: {ping_color}{ping}ms &8| &7TPS: &a{tps}", ""]

📦 Installation

  1. Put TabPlugin.jar in your plugins/ folder.
  2. Restart the server.
  3. Edit plugins/TabPlugin/config.yml and run /tabping reload.

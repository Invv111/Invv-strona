InventorySee

A lightweight moderation plugin that lets staff view and edit players' inventories and ender chests — online and offline — safely, live, and without item duplication.

Supports Minecraft 1.21 → 26+ on Paper, Purpur, Folia and Spigot (one jar for all of them).

✨ Features

  • /invsee <player> – full inventory: hotbar, storage, armor and off-hand.
  • /ecsee <player> – the player's ender chest.
  • Offline players – open and edit inventories / ender chests of players who are not on the server. Changes are saved straight to their player file (a .dat_old backup is kept).
  • View-only mode – give staff invsee.use without invsee.edit and they can only look, not touch.
  • Change logs – every edit is saved to plugins/InvSee/logs/<date>.log, e.g. Admin edited Steve's inventory: -5 DIAMOND.
  • Configurable messages – all texts and window titles in config.yml (colors with &), so you can translate them into any language. Reload with /invseereload.
  • Live two-way sync – your changes reach the player instantly, and the window refreshes when the player's own items change.
  • No dupes, no item loss – the plugin never overwrites a player with an outdated copy of their inventory. If an offline player joins while you're editing, the window closes safely before the server loads their data.
  • Protected slots – barriers and the player's head can't be taken, moved, shift-clicked, dragged or double-click collected.
  • Folia ready – all reads and writes run on the correct region thread.
  • Zero dependencies – just drop it into plugins/.

📜 Commands

Command Aliases Permission
/invsee <player> /checkinv, /seeinv invsee.use
/ecsee <player> /checkender, /seeender, /endersee ecsee.use
/invseereload /isreload invsee.reload

🔑 Permissions

Permission What it does
invsee.use Open inventories (view only on its own)
invsee.edit Change items in /invsee
invsee.offline Use /invsee on offline players
ecsee.use Open ender chests (view only on its own)
ecsee.edit Change items in /ecsee
ecsee.offline Use /ecsee on offline players
invsee.reload Reload the config
invsee.* Everything above

All permissions are given to OP by default.

🧩 Slot layout (/invsee)

Slots Content
1–36 Hotbar + main inventory
37–40 Helmet, chestplate, leggings, boots
41 Off-hand
42–44 Barriers (locked)
45 Player head (locked)

✅ Requirements

  • Paper / Purpur / Folia / Spigot 1.21 – 26.x
  • Java 21+ (Java 25 for Minecraft 26.x)
  • Offline players need Paper, Purpur or Folia (not available on plain Spigot)

📢 AnnounceX - Advanced Announcement System

🎯 What is it?

AnnounceX is a powerful Minecraft 1.21+ plugin for displaying beautiful announcements! Show messages in the center of screen (title) or on the top bar (bossbar) with custom durations, sounds, and particle effects! 🎉

✨ Features

  • 📺 Title announcements - Large text in center of screen
  • 📊 BossBar announcements - Animated bar at the top
  • ⏰ Custom durations - 30s, 5m, 1h, 2d, 1h30m
  • 🔊 Sound effects - Pleasant notification sounds
  • ✨ Particle effects - Magical particles around players
  • 🎨 Full color support - All & color codes
  • 🤖 Auto announcements - Configure in config.yml
  • 📊 Real-time tracking - See active announcements with time left

🎮 Commands

📺 Title (Center Screen)

/announcetitle <message>
/announcetitle <time> <message>

Examples:

/announcetitle &c&lIMPORTANT ANNOUNCEMENT!
/announcetitle 30s &c&lSERVER RESTART IN 5 MIN!
/announcetitle 5m &e&lEvent is now active!
/announcetitle 1h &a&l2x EXP Active!

📊 BossBar (Top Bar)

/announcebossbar <message>
/announcebossbar <time> <message>

Examples:

/announcebossbar &d&lWelcome to the server!
/announcebossbar 2m &d&l⚔ PvP Event in progress!
/announcebossbar 1h &6&l💰 Shop sale - 50% off!

🛠️ Management

/announcex                    - Show help
/announcex list              - Show active announcements
/announcex clear titles      - Remove all titles
/announcex clear bossbars    - Remove all bossbars
/announcex clear all         - Remove everything
/announcex reload            - Reload config

⏱️ Time Formats

Format Duration Example
30s 30 seconds Quick messages
5m 5 minutes Short events
1h 1 hour Long events
2d 2 days Weekend events
1h30m 1h 30min Mixed format

🎨 Color Codes

Use & for colors and formatting:

Colors: &0-9, &a-f (black to white) Format: &l bold, &o italic, &n underline, &m strikethrough

Example:

/announcetitle &6&l⭐ &e&nWelcome &6&l⭐

🔑 Permissions

  • announcex.title - Use /announcetitle
  • announcex.bossbar - Use /announcebossbar
  • announcex.admin - Use management commands

⚙️ Config.yml

# Title settings
title-interval: 300          # Auto announcement interval (seconds)
title-fade-in: 10           # Fade in (ticks)
title-stay: 60              # Default duration (ticks)
title-fade-out: 10          # Fade out (ticks)
title-play-sound: true
title-show-particles: true

title-announcements:
  

# BossBar settings
bossbar-interval: 180        # Auto announcement interval (seconds)
bossbar-duration: 100        # Default duration (ticks)
bossbar-color: PURPLE        # PINK, BLUE, RED, GREEN, YELLOW, PURPLE, WHITE
bossbar-play-sound: true

bossbar-announcements:

🎯 Pro Tips

  1. 🎨 Don't overdo colors - 2-3 colors per message
  2. ⏰ Quick: 10-30s, Important: 5m+
  3. 📊 BossBar for ongoing events
  4. 📺 Title for urgent messages
  5. 🔄 Check /announcex list before sending new
  6. 🧹 Clean up with /announcex clear all
  7. ✨ Use emojis: ⭐ 💎 ⚔ 🏆 💰 ❤ ⚡

🚀 Quick Start

# Welcome message (1 minute)
/announcetitle 1m &6&l⭐ WELCOME! Check /rules

# Daily vote reminder (5 minutes)
/announcebossbar 5m &b&l💎 Vote with /vote!

# Event announcement (30 minutes)
/announcebossbar 30m &d&l⚔ Tournament! /warp arena

# Check what's running
/announcex list

# Clear all
/announcex clear all

🐛 Troubleshooting

Not showing?

  • Check permissions
  • Use correct time format: 30s not 30
  • Verify config settings

Stop early?

  • /announcex clear titles or /announcex clear bossbars

Colors not working?

  • Use & not §

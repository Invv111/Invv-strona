🚀 TPA - Simple, Fully Customizable Teleport Requests

A teleport request plugin that is easy for players and gives admins full control. Click [ACCEPT] in chat, wait for the countdown, and you're there.

✅ One jar for Spigot, Paper, Purpur and Folia - Minecraft 1.20 up to 26.3

🧩 Compatibility

Supported
Minecraft 1.20 - 26.3
Server software Spigot, Paper, Purpur, Folia
Java 17 or newer

The plugin detects your server software at startup - no extra downloads, no separate Folia version.

✨ Features

🖱️ Clickable Chat Buttons

  • Click [ACCEPT] or [DENY] - no typing needed
  • Hover tooltips on every button
  • Got several requests at once? Each one has its own buttons, or use /tpaaccept <player>

📍 /tpa and /tpahere

  • /tpa <player> - ask to teleport to someone
  • /tpahere <player> - ask someone to teleport to you
  • /tpacancel - changed your mind? Cancel your request
  • /tpatoggle - don't want to be disturbed? Turn requests off (remembered after a restart)

⏱️ Three Separate Timers

Most plugins have one cooldown. TPA has three:

Timer Default What it does
Request cooldown 30s Stops request spam
Teleport cooldown 60s Limits how often a player can actually teleport
Request expiry 60s Old requests are removed automatically

Players can send a new request after 30 seconds, but can only teleport once a minute - great for survival servers. Leaving and rejoining does not reset cooldowns.

🎮 Made for PvP

  • Countdown before teleporting (default 3 seconds)
  • Moving cancels the teleport - looking around is fine, taking a step or jumping is not
  • Optional: taking damage cancels the teleport - no escaping from fights
  • Teleports can be blocked by combat and region plugins

🔔 Update Notifications

  • The plugin checks Modrinth for new versions every few hours
  • Admins get a chat message with a [DOWNLOAD] button when they join
  • Can be turned off in the config

🎨 Change Everything

  • Every message can be edited - no hardcoded text
  • & color codes and hex colors (&#ff8800)
  • Set a message to "" to hide it
  • Every sound can be changed or turned off, with volume and pitch
  • Use sound names (ENTITY_ENDERMAN_TELEPORT) or keys (entity.enderman.teleport) - resource pack sounds work too
  • /tpareload applies changes without a restart
  • After updating the plugin, new options are added to your config automatically - your settings are kept

🎵 A Sound for Every Action

Action Default sound
Request sent Experience orb
Request received Note block pling
Countdown Bell every second
Teleported Enderman teleport
Denied Villager "no"
Cancelled Glass break

📜 Commands

Command Aliases Description
/tpa <player> /teleportask Ask to teleport to a player
/tpahere <player> /tpaskhere Ask a player to teleport to you
/tpaaccept [player] /tpaccept, /tpyes Accept a request (the newest one if no name is given)
/tpadeny [player] /tpdeny, /tpno Deny a request (the newest one if no name is given)
/tpacancel /tpcancel Cancel your request
/tpatoggle /tptoggle Turn receiving requests on or off
/tpareload Reload the config

🔑 Permissions

Permission Default Description
tpa.use Everyone /tpa, /tpaaccept, /tpadeny, /tpacancel
tpa.here Everyone /tpahere
tpa.toggle Everyone /tpatoggle
tpa.bypass.cooldown OP Ignore all cooldowns
tpa.bypass.delay OP Teleport instantly, without the countdown
tpa.reload OP /tpareload
tpa.update.notify OP See update messages on join
tpa.admin OP All permissions above

⚙️ Example Configs

Dramatic 10-second teleport (PvP):

teleport-delay:
  delay: 10
  show-countdown: true
  cancel-on-move: true
  cancel-on-damage: true

Instant teleport, but no spam (creative / lobby):

cooldown:
  tpa-cooldown: 120
teleport-delay:
  delay: 0

Silent mode: set enabled: false for every sound.

📦 Installation

  1. Download the jar
  2. Put it in your server's plugins folder
  3. Restart the server
  4. Edit plugins/Tpa/config.yml if you want, then run /tpareload

Perfect for: survival servers that need fair limits, PvP servers that need combat-safe teleports, creative servers that want speed - and any server that wants it to just work. 🚀

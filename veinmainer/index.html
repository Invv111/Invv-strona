⛏️ VeinMiner

Mine one ore, get the whole vein.

VeinMiner adds a real Vein Miner enchantment to the game. Put it on a pickaxe, sneak, break one ore, and every connected block of the same ore comes out with it.

✅ Paper 1.21+ · Java 21

💬 Found a bug or have an idea? Tell us on Discord.

✨ Features

  • ⛏️ Whole veins in one hit. Up to 64 connected blocks at once.
  • 🎯 Ores only. Stone, dirt and your builds are never vein-mined.
  • 📚 A real enchantment. Added with an auto-generated datapack and applied in an anvil like any other book.
  • 🕹️ You're in control. It only triggers while sneaking.
  • 🔧 Fair durability. The pickaxe loses 1 durability per block mined.

⛏️ Supported ores

Overworld: coal, iron, gold, diamond, emerald, lapis, redstone and copper, including all deepslate variants. Nether: nether gold and nether quartz.

🎮 How to use

  1. Run /veinminer to get a Vein Miner I book.
  2. Combine it with a pickaxe in an anvil.
  3. Hold the pickaxe, sneak and mine an ore. 💥

📜 Commands & permissions

Command Description Permission Default
/veinminer Get a Vein Miner enchanted book veinminer.use OP

⚙️ How it works

  • Searches the 6 neighbouring blocks (up, down, north, south, east, west) for the same ore type.
  • Stops at 64 blocks.
  • If the pickaxe breaks mid-vein, mining stops and you hear the break sound.

  2. Start the server. A datapack is created in world/datapacks/veinminer/.

⚙️ Mechanics Vein Mining:

  • The plugin searches for all adjacent blocks of the same ore type
  • Maximum 64 blocks at once
  • Checks only 6 directions (up, down, left, right, front, back)

Tool Durability:

  • The pickaxe loses 1 durability for each mined block
  • If the pickaxe breaks, it disappears from your hand
  • You hear the item breaking sound

Activation Conditions:

  • ✅ Player is holding Shift
  • ✅ Holding a pickaxe with Vein Miner enchantment
  • ✅ Mining block is an ore
